# Project Agent Starter

一套可重複使用、不依賴特定框架的 AI 程式開發代理範本。

透過精簡的常駐代理規範與可重複使用的工作流程，協助 AI 程式開發代理自主執行、在必要時釐清需求、維持程式碼品質，並依據證據安全清理程式碼庫。

[English](../../README.md) | 繁體中文

## 功能

- **自主開發**：獨立完成低風險、可回復的任務。
- **條件式需求釐清**：只有未決事項會實質影響結果時才提問。
- **有效率的驗證**：執行相關檢查，避免不必要的重複測試。
- **安全程式碼清理**：移除遺留程式碼或測試前，先提出證據。
- **代理規範維護**：讓常駐專案規則保持精簡且符合現況。
- **深度程式碼庫稽核**：重大清理時，按需使用六階段流程。

## 快速開始

1. 在 GitHub 點選 **Use this template**。
2. 使用範本建立新的儲存庫。
3. 閱讀根目錄的 [AGENTS.md](../../AGENTS.md)，依專案情況調整。
4. 必要時補上專案需求與驗收標準。
5. 開始與 AI 程式開發代理協作。

本儲存庫只有 Markdown 範本，無須安裝或建置。套用到既有專案時，請整合現有規範，避免直接覆蓋。逐步加入已確認的建置／測試指令、相容性要求與專案邊界。若代理不會自動讀取 `AGENTS.md`，請明確要求它閱讀，或從該工具的規範入口引用。

## 執行安全稽核

保留本儲存庫結構時，將以下內容交給代理：

```text
請閱讀 i18n/zh-TW/prompts/SAFE_CODEBASE_AUDIT_ZH_TW.md，依照其中的六個階段對目前專案進行深度稽核。這次先完成唯讀分析及清理計畫，不要修改或刪除任何檔案，等我審核並明確批准後再執行。
```

六階段涵蓋理解專案、深度稽核、證據與風險分類、先提案後執行、精準驗證、成果報告。唯讀任務只完成分析、計畫與報告；取得批准後才實作與驗證變更。請針對具體批次確認範圍、驗證方法及回復方式。無法證明安全的候選項目應保留；真正的 Bug 應修復根因，不得弱化測試來掩蓋。

## 語言選擇

根目錄與 `prompts/` 的英文文件為主要維護來源；`i18n/zh-TW/` 存放對應繁體中文翻譯。

若希望新專案以繁體中文為主要規範，請將本目錄的 `AGENTS.md`、`REQUIREMENTS.md`、`AGENTS-MAINTENANCE.md` 複製到新專案根目錄，再將中文稽核提示詞複製到新專案的 `prompts/`。覆蓋前先檢查既有內容。只保留 `i18n/` 中的翻譯，不會將它切換為專案根目錄的規範入口。

完成上述複製後，稽核指令可改為：

```text
請閱讀 prompts/SAFE_CODEBASE_AUDIT_ZH_TW.md，依照其中的六個階段對目前專案進行深度稽核。這次先完成唯讀分析及清理計畫，不要修改或刪除任何檔案，等我審核並明確批准後再執行。
```

不搬動檔案時也可直接使用上方 `i18n/zh-TW/prompts/` 路徑；稽核對象仍是目前專案根目錄。

## 貢獻與雙語維護

歡迎提出 Issue 或 Pull Request。變更應聚焦並保持框架中立。請同步更新英文來源及繁體中文翻譯，維持相同的安全界線與批准條件；若翻譯尚未完成，請在 Pull Request 指出受影響段落。

提交前檢查相對連結、範例路徑、中英文語意與六個稽核階段。單次工作流程放在 `prompts/`，避免讓常駐規範膨脹。本文件範本沒有應用程式測試套件；使用它的專案應執行自身所需的驗證。
